# Satashi Code Examples

Небольшие учебные и самостоятельные проекты из локальной папки `code`. Здесь собраны упражнения Python и Git, отдельные скрипты и статические веб-макеты. Каждый пример можно изучать независимо.

## Разделы

| Папка | Что внутри |
| --- | --- |
| `learning-projects/` | Упражнения по Python, файлам и работе в терминале. |
| `standalone-scripts/` | Примеры визуализации, обработки изображения и отдельных задач. |
| `web-projects/` | Простые HTML-макеты и концепт страницы SatashiDCS. |

## Запуск

Для HTML-файлов достаточно браузера. Python-скрипты запускаются отдельно; некоторые требуют дополнительные библиотеки, графическую среду или разрешённый тестовый сервер. Перед запуском прочитайте комментарий в начале файла и проверьте настройки внутри него. Скрипты с сетевой нагрузкой используйте только на системах, которые вам разрешено тестировать.

В репозиторий не включены локальные настройки, сессии и секреты. Каждый пример является учебным материалом, а не готовым рабочим сервисом. Лицензия на повторное использование не указана.
